# FieldFlow 电学实验台

把电学题画成电路,看它真实运行时的样子。电流方向、电势分布、电场分布都按严格的高中概念算出来:电流是单位时间通过截面的电荷量 I = q/t,电压是两点间的电势差 U = φA − φB。

## 用法

浏览器直接打开 index.html,什么都不用装。

- 左栏选元件,点网格边放置;悬停有半透明预览
- 导线按住拖动,L 形直角布线,松手整条落线;单击放单独一段
- 点开关符号的中部,开合开关
- 选中元件后,R 翻转两端,Del 删除
- 空格拖拽平移,滚轮缩放,F 适配视图
- 双击导线放截面探针,右栏实时演示 I = q/t
- 电势模式下双击节点,把该点设为 φ = 0 参考

## 能看什么

顶栏五个开关:电流粒子、电子流向、电势着色、电势数值、电场箭头。右栏有仪表读数、逐元件 U/I/R/P 明细、元件检查器(每个元件附严格定义式,比如"R = U/I 只是量度式")、电势图例。单回路电路还会画出绕回路一周的电势曲线,电池把电势抬高、电阻把电势压低,一目了然。

## 物理模型

节点电压法,部分主元高斯消元。导线每格 1 mΩ,电池带 1 mΩ 内阻,电流表 0.1 mΩ,电压表按开路处理。短路时电流达到几百安培并被标记;断路时各支路电流为零。两个可以亲自验证的结论:

- 电压表并在断开的开关两端,读数等于电源电动势
- 电压表的探针线电流恒为零,不影响原电路
