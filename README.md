# FieldFlow 电学实验台

在方格纸上搭一个直流电路,看它跑起来。电流粒子沿导线移动,导线按电势着色,每个元件的电压、电流、电阻和功率实时算出来。

![FieldFlow 界面](src/assets/hero.png)

## 这是什么

FieldFlow 是一个给初中电学用的画图工具。你放电池、开关、电阻、灯泡这些元件,用导线把它们连成回路,程序用节点电压法算出每个节点的电势和每条支路的电流,再把结果画在图上。

右栏列出每个元件的读数,元件检查器里写着它的定义式。电阻旁边是 $R = U/I$,注明这是量度式。电压表旁边是 $U = \varphi_+ - \varphi_-$,读数就是两个接线柱的电势差。电流按 $I = q/t$ 定义,画布上的截面探针会累计通过截面的电荷量。

## 它不能做什么

这个工具只处理直流电路。磁场和电磁感应不在范围内,电容器充放电也没有做。

元件按理想模型计算。导线默认没有电阻,电压表内阻视为无穷大,灯泡按定值电阻处理。真实灯泡的灯丝电阻随温度升高,实验室读数会和这里的数字有出入。

它不会替你解题。电路要自己搭,参数也要自己调。

## 和 PhET、Falstad 的区别

[PhET 电路模拟](https://phet.colorado.edu/zh_CN/)覆盖从小学到大学的很多主题,配套的引导活动和教学材料很完整。[Falstad Circuit Simulator](https://www.falstad.com/circuit/)擅长模拟电路分析,能看示波器波形和频率响应。

FieldFlow 只做初中直流电路,重点放在定义和读数上。每个元件旁边有定义式,右栏的电压和电流直接对应 $I = q/t$ 与 $U = \varphi_A - \varphi_B$。

要覆盖更多主题,PhET 的范围更广;分析复杂的模拟电路时,Falstad 的功能更全。要把初中电学的概念理顺,这个工具的元件说明写得更细。

## 功能

- 元件吸附在格点上,导线只能水平或竖直连接,按住一条边拖动可以连续铺线
- 电池有可调电动势和内阻,默认 0.1 Ω,接近一节干电池
- 开关点一下开合,断开的开关两端可以测到电压
- 滑动变阻器直接拖滑片,阻值连续变化
- 电流表串联接入,电压表并联接入,读数实时更新
- 五层可视化:电流粒子、电子流向、电势着色、电势数值、电场箭头
- 双击导线打开截面探针,演示 $I = q/t$
- 撤销和重做,最多 100 步
- 电路保存在浏览器本地,也可以导出为 `.ff.json` 文件
- 分享链接把整个电路编进地址栏,打开就能看到同一张图
- 深色模式,移动端支持双指缩放和拖拽平移
- 单回路电路画出绕行一周的电势曲线

## 怎么用

1. 从左边元件栏选一个元件,再点方格纸上的边放下它。悬停时会显示半透明预览。
2. 选导线,按住一条边拖动,松手落下一整段 L 形折线。单击可以放单独一段。
3. 点开关符号中间,闭合或断开。
4. 选中元件后按 `R` 翻转两端,按 `Delete` 删除。
5. 按住空格拖动平移画布,滚轮缩放,按 `F` 回到全图。
6. 双击导线打开截面探针。在电势模式下双击节点,可以把它设为 0 V 参考点。

## 本地运行

需要 Node.js 20.19 或更新版本(Vite 8 的要求)。

```bash
npm install
npm run dev
```

打开终端里显示的地址,通常是 `http://localhost:5173`。

## 构建

```bash
npm run build
```

产物在 `dist/`。部署到静态托管时,把 `dist/` 整个目录传上去即可。路由使用 hash 模式,不需要服务端重写规则。

## 物理约定

- 电流方向按正电荷流向约定。电子流向是可选图层,打开后粒子反向移动。
- 电池符号的长线为正极,边数据里 `b` 端为正极,电动势把电势从 `a` 抬到 `b`。
- 理想导线是等势体,两端点合并为一个超节点。理想导线内部的电流分布按最短路路由计算,对串联链和星形结点精确,并联网格上是合理近似。
- 电压表按开路处理,探针线电流为 0。
- 短路判据是电池端电压塌陷。电流超过 0.1 A 且端电压低于电动势的 30% 时判为短路,任一支路电流超过 20 A 也判为短路。
